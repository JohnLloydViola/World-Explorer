# This is a website that lets you search your country and find various informations on it.

# React + Vite Project
A React application built with Vite.

## Prerequisites
Before getting started, make sure you have Node.js installed on your computer.

## Installation
Install the project dependencies:
```bash
npm install
```

## Run the Development Server
Start the development server:
```bash
npm run dev
```
After the server starts, open the local URL displayed in your terminal.
